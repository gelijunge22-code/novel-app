# 写作台

自研后端 + 移动端网页 + 安卓客户端。部署在自己的机器上，稿件与设定仅保存在本地。

[快速开始](#快速开始) · [功能](#功能) · [手机客户端](#手机客户端) · [部署到外网](#部署到外网可选) · [许可证](#许可证)

---

## 这是什么

面向长篇写作的完整工具，由三部分组成：

- **后端**：Python（FastAPI），负责数据、模型调用与写作流程编排
- **网页版**：原生 JavaScript，无构建步骤，浏览器直接打开
- **安卓客户端**：封装同一套网页，连接自建服务器

仓库不包含任何书稿、设定或密钥。克隆后为空实例，内容全部由使用者自行创建。

## 快速开始

需要 Python 3.11 或更高版本。

```bash
git clone https://github.com/gelijunge22-code/novel-app.git
cd novel-app

python3 -m venv server/venv
server/venv/bin/pip install -r requirements.txt

server/venv/bin/python -m uvicorn server.app:app --host 127.0.0.1 --port 8899
```

浏览器打开 **http://127.0.0.1:8899/** 即可使用。

### 首次登录口令

每台机器首次启动时随机生成，不共用默认值。获取顺序：

1. 启动前设置环境变量 `NOVELAPP_INIT_PASSWORD`（需自行指定时使用）
2. 未设置时，启动过程中在控制台输出
3. 同时写入 `data/initial-password.txt` 与 `data/口令.txt`（权限 600）

```bash
cat data/口令.txt
```

### 口令找回与修改

登录后进入 **设置 → 关于**，页面直接显示当前口令，并提供「复制」与「换一个」。

口令同时保存在以下位置：

- 后端启动时的控制台输出
- `data/口令.txt`、`data/initial-password.txt`（权限 600）

修改口令（立即生效，无需重启）：

```bash
python3 tools/set_password.py            # 随机生成
python3 tools/set_password.py 新的登录口令   # 指定为新值
```

也可在客户端「设置」中修改，或通过 **设置 → 关于 → 换一个** 完成。
以上三种方式均会同步更新 `data/口令.txt`。

## 功能

### 写作流程

一次生成可拆分为多个环节：出方案 → 逐条挑刺 → 取料查证 → 写正文 → 复审改稿。
每个环节为独立的模型调用，写作与审阅互不折中。

三种工作方式：**讨论 / 计划 / 执行**。每种均可选择执行模式：

| | 分工 | 单人 |
|---|---|---|
| 执行主体 | 计划、取料、查证、写作、挑刺分别由不同角色承担 | 由同一角色依次完成全部环节 |
| 适用 | 正式写作，注重质量 | 小幅修改，注重速度 |
| 取舍 | 耗时较长，消耗较多额度 | 无交叉审阅 |

写正文环节会将稿件写入文件；讨论与计划环节不修改任何文件。

### 模型设置

每个模型可单独打开参数面板：上下文上限（1M / 256K / 128K 等快选）、单次最大输出、
推理模型开关，以及高级参数 JSON（直接并入请求体）。修改仅作用于该模型。

### 世界引擎

将人物、势力、门派等记录为带状态的主体，事实与关系存入数据库。
支持从设定文件批量抽取事实，并检测新写正文与既有设定的冲突。

### 文字检查

内置 568 条中文写作规则（填充词、机械过渡、公式化排比等），成稿后标出问题句。
规则表可自行修改。

### 听书

按段落朗读稿件，支持边写边听。

### 联网搜索

默认关闭。需要时在对话框旁开启，仅在开启状态下发起请求。
默认与主创角色共用同一模型。

## 手机客户端

获取方式：

**一、从自建网页下载（推荐）**

进入写作台 → **设置 → 关于 → 安卓安装包**。下载所得为该实例对应的客户端。

**二、从仓库获取**

[`app/写作台-通用版.apk`](app/写作台-通用版.apk) 为空白通用版：不含书稿，也不含服务器地址。

两种安装包内容一致。首次打开需在登录页点击「服务器设置」，填入自建服务器地址，
再使用本人口令登录。

从源码自行打包（需 Android SDK 与 JDK 17）：

```bash
SEED=0 bash apk/build.sh                               # 空白通用版
SERVER=http://你的地址:8899/ SEED=0 bash apk/build.sh    # 内置服务器地址
```

## 部署到外网（可选）

前端与接口共用同一端口，前置反向代理即可。仓库提供现成的 systemd 服务：

```bash
cp deploy/novelapp.service ~/.config/systemd/user/
systemctl --user enable --now novelapp
```

> **公网部署必须自行增加认证层**（Caddy / Nginx 的 basic auth 均可）。
> 不应将无口令校验的端口直接暴露到公网。

## 更新

在网页中点击 **设置 → 关于 → 更新 → 检查更新**（支持一键更新，10 秒内返回结果）。
变更内容与原因见 [`docs/更新记录.md`](docs/更新记录.md)。

## 数据

```
data/books/<书名>/          正文、设定、角色卡、大纲
data/app.db                 会话、世界引擎的实体与事实、模型配置
data/initial-password.txt   首次启动生成的口令
```

- 全部数据保存在本机，`.gitignore` 已排除 `data/`，不会误提交至仓库
- 删除书籍时先移入 `data/trash/`，不直接抹除
- 备份方式：复制整个 `data/` 目录

## 目录结构

```
server/          后端：路由、引擎、数据层
  routers/       业务接口
  engine/        编排、世界引擎、文字检查、联网搜索、语音
frontend/        网页版（原生 JS + CSS）
apk/             安卓客户端
tools/           脚本：口令修改、依赖自检、打包校验
deploy/          systemd 服务与反向代理示例
```

后端为 Python，前端为原生 JavaScript，无构建步骤，修改后刷新即可生效。
