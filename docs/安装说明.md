# 安装说明（手机写作台 2.0.5）

> 这份是给**用户**看的：怎么装、升级要不要先卸载、卸载会丢什么。

## 一、下载哪个文件

安装包在服务器上：

| 地址 | 说明 |
|---|---|
| `http://<你的服务器地址>/novel/apk` | 直接下载最新安装包（约 27 MB） |
| 或者在 App 里：**书架 → 左上角菜单 → 设置 → 关于 → 安卓安装包 → 下载 / 更新** | App 会自己下载并拉起安装界面 |

文件名：`手机写作台.apk`（同一份内容的副本：`apk/app-release.apk`；两者 sha256 一致）。

这一版：**2.0.5 · versionCode 25 · 27,695,825 字节** · sha256 `fc8c7f426e3683350bbbd40c2e87e75f72ca45b331caf51123d5c8df412f70c8`。

## 二、怎么装

1. 用手机浏览器打开上面的地址，下载。
2. 点安装包 → 系统会问「是否允许安装未知应用」，允许一次。
3. 装完点「打开」。

**首次打开会问你密码** —— 就是原来网页版那个密码（服务器上那份配置里的口令）。
输一次之后就记住了，以后不用再输。

## 三、从旧版升级：直接装就行（不用卸载）

只要**签名一致**，安卓会直接覆盖升级，**数据不丢**：

- 你手机上原来装的那版签名指纹是
  `428cb931438c673fb2660e9e781d35ac4e6a3215edf4d0cf2c961f02337e8aa0`
- 这一版**用的是同一把钥匙**，指纹一模一样（每次打包都会自动比对，见 `tools/verify_apk.sh` 第 3 节）

所以：**下载 → 点安装 → 完成**，书稿、设置、阅读进度都还在。

## 四、万一装不上（签名对不上）

如果你手机上装过**别的来源**的包（比如从别处下载的、或者被改过的版本），
安卓会拒绝安装，报「应用签名不一致」。这时候只能：

1. **先在手机上卸载旧版**
2. 再装新版

**卸载会丢什么：**

| 会丢 | 不会丢 |
|---|---|
| App 在本机存的东西：**没上传的草稿、本地阅读进度、本机缓存**（都在手机的应用私有目录里，卸载即清） | **服务器上的书稿一个字都不会丢** —— 书稿存在服务器 `/home/ubuntu/novel-app/data/books/`，跟装不装 App 无关 |
| 设置里的偏好（主题、字号这些，重装后要再设一次） | 服务器上的设定、剧情、素材、质检记录、导出文件 |

**建议**：卸载前先在 App 里 **工具 → 备份 → 现在打一份备份**，
或者 **工具 → 导出 → 整包导出**，把书稿拿到自己手里（这也是用户一直强调的"数据自持"）。

## 五、装完之后

- **联网时**：全部功能可用（书架、写作、设定、剧情、质检、统计、导出、AI 写正文……）。
- **断网时**：App 照样能打开（界面在包里，不是网页）；
  读过的章节能接着看；设置能改。**调模型写正文需要联网**，断网会明确告诉你。
- **设置 → 关于**里有一行「**离线后端**」：
  - 显示「本机运行 · 断网可用」= 手机里那份后端跑起来了，断网也能写、能看；
  - 显示「在服务器上 · 需要联网」= 手机里那份没起来（不影响用，只是要联网）；
  - 后面那个「重试」按钮可以再试一次。

## 六、版本与更新

- 当前版本：**2.0.5（versionCode 25）**
- 服务器上放新版本后，App 的 **设置 → 关于 → 安卓安装包** 会自动变成「有新版本 · 下载更新」，
  点一下就在 App 里下载并拉起安装界面（不会跳浏览器）。

## 七、出问题了怎么办

**打开就闪退 / 一片空白**：这一版专门为这两种情况做了两件事：

1. **黑色匣子**：崩过一次之后，下次打开 App **会自动弹一份「启动故障报告」**，
   上面写清了机型、安卓版本、出错位置。**长按可以全选复制**，右边还有「分享」按钮，
   把它发回来就能定位。
2. **不会白屏**：就算后端全连不上，App 也会把界面放出来，并明确告诉你
   「连不上服务器：检查网络，或看看服务器地址对不对」，而不是干等。

其它日志位置（可以不管，排错时我才要）：
`Android/data/com.nbapp.desk/files/` 下的 `ondevice.log`、`crash-*.log`。
