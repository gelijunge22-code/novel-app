# 踩过的坑 · 下（前端观感 / APK 打包）

## D. 前端观感（用户的雷区，一条都别碰）

- **水波纹曾经"框一大块在震"**：`app.js` 里**同时跑着两套波纹实现**，
  旧那套半径是 `max(w,h) * 2.1` —— 一个 54px 的小按钮能糊出 113px 的一大团，
  一次点击冒两个圈。
  **现在的规矩（照抄）**：
  - 只留**一套**波纹；半径 `clamp(hypot(w,h)*0.42, 26, 64)`，
    小按钮整颗亮、大卡片只在指尖起一圈
  - 元素不是 `relative` 就临时加、`overflow: visible` 就临时设 `hidden`，
    动画结束**还原行内样式**（不改类、不留后患）
- **容器级的 `:active` 要删干净**：`.settings-row:active`、`.row:active`、
  `.book-card:active{scale}` —— 点行里一个小按钮，**整行**跟着变色缩放。
  用户原话："我想要的是我点一个球，那么就只有这个球的身体有波动。"
- **返回键要分层**：在工具详情页（含文件浏览器多级目录）按返回，
  以前**一步跳回书架**，丢掉中间层级。要一层一层退：详情 → 宫格 → 书架 → 再按问退出。
- **过渡动画要好看**：用户明确吐槽过"点开小说的界面依然是过渡动画，丑的不行"。
  现在的已经调好，**别改坏**。
- 用户对前端有个总评价：**"现在已经很好看了，这个可以保留"** ——
  所以你的活是**加功能、更好看**，绝不是重做。

## E. APK 打包（自研壳，无 Gradle）

这套壳用 `aapt2 + javac + d8 + apksigner` 直接打，工具在
`/home/ubuntu/android-sdk/build-tools/34.0.0/`。**注意：这些工具不在 PATH 上，要用全路径。**

**踩过的坑**：
1. **版本号曾经写死在 Java 里**（`VERSION_CODE = 2`），清单已经 1.2 了它还说 1.1 →
   JS 问到的版本永远是旧的 → 关于页**永远提示"有新版本"**，用户升到最新还被催更新。
   **已修**：改成从 `PackageManager` 读（清单是唯一出处）。
   你做新 App 时，版本号也**只许有一个出处**。
2. **清单里的 `versionCode`/`versionName` 就是真版本**，`aapt2 dump badging` 能验。
   改版本要同时改清单，别散落在多处。
3. **验证要动真家伙**：
   - `aapt2 dump badging <apk> | grep ^package`
   - `dexdump -f <apk> | grep <方法名>`（注意 dexdump 对方法引用的显示方式，
     必要时 `unzip` 出 `classes.dex` 用 `strings` 查）
4. **签名密钥不在仓库里**：keystore 留在 `/home/ubuntu/nbapp/apk/`，
   **口令不许写进任何文档、日志、git**。要打包时从本机读。
5. **改完前端不用重打包**（前端在服务器上）；但**这次不一样** ——
   用户要求前端**内嵌进 APK**，所以前端一改，APK 就得重打，记得把版本号往上走。
6. **App 内下载更新**已经打通（App 能自己下载 APK 并弹安装）。新的 App 要保留这个能力，
   而且**不能出现"已是最新还提示有新版"**这种蠢事。

## F. 干活方式（我作为监督人最在意的一条）

- **别注水**：不许复制改名凑文件、不许留空壳函数、不许留死代码。
- **别偷懒提前收工**：没做完就继续做，别写个 TODO 就说完成。
- **每轮结束都要留下可验证的证据**：跑通的日志、截图、接口自测结果，写进 `docs/进度.md`。
- **一轮只汇报一次**，别每做一点就长篇大论。
- 遇到拿不准的**先做合理默认**，把决定记进 `docs/决策记录.md`，别停下来等人。

## 中文路径必须百分号编码（第 33 轮 · 监督人实测）

请求里的中文**不编码就会死在 HTTP 层**（连业务代码都进不去）：

```
GET /api/tts/seg?slug=…&path=第001章-荒原雪夜.md        → 400 Invalid HTTP request received.
GET /api/tts/seg?slug=…&path=%E7%AC%AC001%E7%AB%A0-…    → 200 audio/mpeg
```

规矩：**任何**拼 URL 的地方都要编码 —— `fetch`/`XHR` 的查询串（前端的 `qs()` 已经
`encodeURIComponent`，照着用）、`<audio src>` / `<img src>`（走 `API.media()` / `API.ttsSegUrl()`）、
`EventSource`（`API.abs()`）、转发链接、下载地址。新写一处就照着现成的函数拼，别手写 `${path}`。
