# 踩过的坑 · 上（后端 / 听书 / 部署）

> 这些不是理论，是**真金白银试出来的**。照着躲，能省你几天。

## A. 听书 TTS（最坑的一个）

**症状**：用户点听书，半天不出声，以为坏了。

**真因**：后端把**整章**塞给 `edge-tts` 一次性 `save()` 成一个 mp3。
一章 4000 字 ≈ 13 分钟音频 / 4.7MB，**合成要几十秒**。这几十秒里前端毫无变化。

**正确做法（已验证可行）**：
- 后端把正文**按句切成小段**（约 240 字/段），提供两个接口：
  - `GET /api/tts/segments?book=&path=` → 只回段数、字数（很便宜）
  - `GET /api/tts/seg?book=&path=&i=N` → 回第 N 段的 mp3，**按段缓存**
- 实测：**第一段 1.7 秒出声**（原来要几十秒）；缓存命中 0.03s
- 前端：一段播完自动接下一段，并**预取下一段**（等播完再去要会有空档）
- 一章读完自动接下一章（`pathNext` → 载入下一章 → 重新开始）

**前端三个坑**：
1. **按钮必须有状态**：`听书` → `准备中`（转圈）→ `停止`（暂停图标+底色块）。
   以前只换了个几乎看不出差别的颜色，用户完全不知道开没开 —— 这就是他说的
   "喇叭的 UI 会变到别的地方"。
2. **换音色/语速要静默重启**，别弹"已停止听书"再自己重开（很跳）。
3. **跟读**：用户要"读到哪、页面跟到哪"。按段进度换算页码：
   `page = round(seg / (count-1) * (pages-1))`，只跟"开读时那一章"。

**音频质量**：用户觉得现在的 edge-tts 声音**难听**，指定要试 CosyVoice
（https://cosyvoice.org/ ，音色可克隆，但**一次只能生成 120 字**，所以要靠分段来兜）。
这条我在并行处理，你先把**接口形状设计成可换引擎**（`engine` 参数），别写死。

## B. 服务与部署

- **改代码重启不生效**：系统里挂着 SSE 长连接时，uvicorn 会一直等它断，
  默认要等满 90 秒才被 SIGKILL。表现就是"改了代码、重启了、旧的还在跑"。
  **unit 里必须设**：`TimeoutStopSec=7` + `KillMode=mixed` + `SendSIGKILL=yes`。
- **监听地址**：服务**只监听 `127.0.0.1`**，公网一律走 Caddy 反代。
  绑 `0.0.0.0` 等于把带密码的门开在所有网卡上（这个坑刚修过）。
- **重启要有心理准备**：网关类服务改配置要重启才生效，重启会造成短暂中断，
  **动生产服务前必须先告诉我（我会去征求用户同意）**。
- 用 `systemd --user` + `Restart=always`，保证进程死了自己爬起来（用户最恨静默死亡）。

## C. 环境

- **pip 极慢**：必须走国内镜像。首选清华 TUNA
  （`https://pypi.tuna.tsinghua.edu.cn/simple`，完整可靠）；
  腾讯云 `https://mirrors.cloud.tencent.com/pypi/simple/` 快但缺 PEP700 时间，
  uv 解析新包可能报错。npm 已配腾讯云源。
- **Node 版本**：系统自带 v22 偏旧，另有 `Node 24` 在 `/opt/node24/bin`。
- **GitHub 慢**：走代理 `http://本地代理`（本地代理），别抱怨网络。
- **写受保护文件**（AGENTS.md / CLAUDE.md 之类）需要人工批准，会超时作废 ——
  遇到就换个方式写。

## 中文路径必须百分号编码（第 33 轮 · 监督人实测）

请求里的中文**不编码就会死在 HTTP 层**（连业务代码都进不去）：

```
GET /api/tts/seg?slug=…&path=第001章-荒原雪夜.md        → 400 Invalid HTTP request received.
GET /api/tts/seg?slug=…&path=%E7%AC%AC001%E7%AB%A0-…    → 200 audio/mpeg
```

规矩：**任何**拼 URL 的地方都要编码 —— `fetch`/`XHR` 的查询串（前端的 `qs()` 已经
`encodeURIComponent`，照着用）、`<audio src>` / `<img src>`（走 `API.media()` / `API.ttsSegUrl()`）、
`EventSource`（`API.abs()`）、转发链接、下载地址。新写一处就照着现成的函数拼，别手写 `${path}`。
