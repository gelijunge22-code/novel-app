## 0. 铁律

1. **任何可点的东西，按下去必须有反馈。** 没有例外。
2. **任何界面的出现/消失，都必须是"移动"，不能是"闪现"。** 硬切 = 不合格。
3. **任何耗时超过 300ms 的操作，必须立刻有"我在干活"的视觉信号。**
4. **同一类东西走到哪都是同一个动效参数。** 不许一个弹窗 200ms、另一个 350ms。
5. **动效服务于"我从哪来、我到哪去"。** 不是装饰——转场方向必须和导航层级一致。
6. **60fps。** 只动 `transform` 和 `opacity`，不动 `width/height/top/left`。

## 1. 动效参数表（唯一真源，写在 `css/motion.css`）

| 用途 | 时长 | 曲线 | 位移/缩放 |
|---|---|---|---|
| 按下反馈 | 90ms | ease-out | scale .97 |
| 抬起回弹 | 160ms | spring(1,0.6,1.4) | scale 1 |
| 小元素进出（chip/tag） | 180ms | out | 位移 8px |
| 抽屉/弹窗进场 | 240ms | out-quint | 位移 100% |
| 抽屉/弹窗退场 | 180ms | in | 位移 100% |
| 页面 push（进下一层） | 320ms | out-quint | 旧页 -22%，新页 +100→0 |
| 页面 pop（退回上层） | 280ms | out-quint | 反向 |
| Tab 切换（同级） | 200ms | out | 淡 + scale .98→1 |
| 列表条目入场 | 360ms | out | y +14，逐条 +45ms |
| 翻页（仿真） | 动态 | 跟手 | 见 §4 |
| 数值滚动/进度 | 400ms | out | — |

缓动定义：
```
--ease-out:   cubic-bezier(.22,.61,.36,1)
--ease-out-q: cubic-bezier(.16,1,.3,1)      /* 收尾更利落 */
--ease-in:    cubic-bezier(.4,0,1,1)
--ease-spring:cubic-bezier(.34,1.4,.64,1)
```

## 2. 间距 / 圆角 / 字号（视觉统一的唯一真源）

- **间距只用 4 的倍数**：4 / 8 / 12 / 16 / 20 / 24 / 32。不许出现 13px、11px 这种。
- **圆角只有三档**：`--r-s:10px`（小控件）、`--r-m:14px`（卡片/输入框）、`--r-l:20px`（抽屉顶/大卡）。
- **字号阶梯**：11 / 12.5 / 14 / 15 / 17 / 20 / 24。正文用 `--fs`（可调）。
- **图标线宽只有两档**：1.7（普通）/ 2.1（选中）。图标尺寸只有 20 / 22。
- **点击热区不小于 44×44dp**，视觉可以小，热区不能小。
- **同一层级的所有标题、正文、说明文字，颜色只能取 `--ink / --ink-2 / --ink-3` 三档之一。**

## 4. 仿真翻页硬标准

现状不合格：只是把整页绕左边缘 `rotateY` 转过去，没有纸的感觉。

- [ ] **跟手**：手指拖动时纸张实时跟随手指，松手才决定翻不翻（现在只有松手后播放）

### 本轮揪出的两个真 bug（都是「用户根本没法用」级别）
1. **预设页的文本框改不了也存不了**：`onInput` 只设了 `S.dirty`，**没调用 `mark()`**，而 `mark()` 才是解禁「保存」按钮的那个函数。结果：单选按钮能存（走 `mark(true)`），文本框改了按钮还是灰的。已修并跑通「改→存→服务端核对→还原」全链路。

### 这轮踩到的坑（都是真原因，不是猜的）

1. **平台设计上只给「全局」初始化文风库** —— `writer.profile.tsx` 的
   `initializeWriterHome` 第一行就是 `if (ctx.scope !== "global") return;`。
   而它的 `validate()` 在项目作用域下是去**这本书自己的 home**
   （`<书目录>/agents/<profileKey>/`）找文风文件，找不到就报「选择的文风要求不存在」。
   所以保存项目级预设之前，必须把用到的文风/参考正文**落到书自己的 home 里**
   （`_materialize_project_assets`，正文从全局 settings 的 `resource.contents[]` 取）。
2. **平台没有「删除项目级配置」的接口**（只有 put）。直接删
   `<书目录>/.nbook/config.json` 即可 —— 平台每次请求都重读该文件，没有内存缓存，
   删完立即回落全局（实测 `hasOwn: true → false`）。
3. **WAAPI 的 `fill:'both'/'forwards'` 不 cancel 会一直挂着**：元素被钉在
   `opacity:0` / 缩放态，下次切回来新旧动画打架 —— 用户说的那一下「闪」就是这么来的。
   一切转场都要先 `getAnimations({subtree:false}).forEach(a=>a.cancel())`。
4. **「点开书闪屏」的第二条根因是「先切屏、后联网」**：原来 `Shelf.open` 先
   `App.show('reader')`，阅读页空着显示、标题写「载入中…」，等网络回来才蹦字。
   正确做法是 `Shelf.openBook` 先把书和第一章都抓到手（`Reader.preload`），
   再切屏 —— 这样 `openReader` 全程同步，一帧画完，动画期间不会掉字。
5. **章节缓存的 key 必须是「书 + 路径」**：各书的章节路径会长得一模一样
   （模板新建的都是 `manuscript/001-volume/001-chapter/index.md`），只按 path 缓存会串档。
6. 转场只动 `transform` + `opacity`（GPU 合成，不触发重排重绘）。
   千万别在整屏元素上动画 `border-radius` —— 每帧重新栅格化一整屏，必卡。

## 第四轮（2026-09-19 · 把原网页的全部能力搬进 App）

### 干了什么

原网页（小说软件本体）一共 **154 条接口 / 11 个功能域**。这轮把 App 从
「只有书架+阅读+写小说那几件」扩到**全量**：

1. **反代层做成真·全量**：`/nb/{任意路径}` 是 catch-all，方法/查询串/请求体/流式
   全部原样转发。已实测 **63 条 GET 路由，直连平台 vs 走代理，状态码 63/63 完全一致**。
   构造上不可能漏 —— 新增接口不用改代理。
2. **加了「自动开项目」**：平台大量项目级接口在项目没打开时返回
   `409 PROJECT_NOT_OPEN`。现在透传层看到这个响应会**自己把项目打开再重试一次**
   （`_slug_of()` 从查询串或请求体里找 `projectRoot`）。文件树/RAG/历史收件箱
   由 409 全变 200 —— 这是所有项目级功能的前置，不加这层，一半按钮都是死的。
3. **新增「工具」标签页 + 12 件工具**（`js/tools.js` 961 行 / `css/tools.css`）：

   | 分组 | 工具 | 对应平台的什么 |
   |---|---|---|
   | 书稿 | 文件 | `workspace-files/*` 全量：树、读写、新建、重命名、删除、上传、下载 |
   | 书稿 | 封面 | `projects/cover` 传/看/删 |
   | 书稿 | 记忆 | `projects/rag/*`：总览、主体、记忆条目、事件、搜索、重建、体检 |
   | 书稿 | 模型 | `config/models/library`（730 个）、供应商、连通性检查、发现 |
   | AI | 档案 | `agent/profiles/*`：列表、源码、工具清单、编译状态、模板 |
   | AI | 技能 | `agent/skills`（17 个） |
   | AI | 任务 | `agent/jobs`：列表、取消、清理 |
   | AI | 改动 | `workspace-history/*`：收件箱、逐条接受/回滚、差异 |
   | 系统 | 备份 | `passport/*`：状态、备份列表、密钥、设备关联 |
   | 系统 | 会话 | `agent/sessions`（41 个）+ 运行痕迹 `agent/traces/recent` |
   | 系统 | 账号 | `admin/users` |
   | 系统 | 关于 | `app/version`、`app/logs` |

   每件都对着**真实返回结构**写（先用 `tools/probe_shapes.py` 探结构，再造界面），
   不凭空猜字段。

4. **修掉的真 bug**：
   - **听书 500**：`/api/tts` 把 `rate` 原样丢给 edge-tts，而 edge-tts 只认
     `+0%` 这种串。前端/老客户端传的是倍数 `1`、`1.2` → 只要不是默认速度就炸。
     加了 `_norm_rate()` 收口：倍数、百分比都收，非法值兜底成 `+0%`，超范围夹紧。
     实测 `rate=1` 从 500 变 200（4.7MB 真音频）、`1.2` 也出 3.9MB。
   - **服务重启一次卡 90 秒**：unit 文件没写 `TimeoutStopSec`，默认 90s 内
     systemd 一直等，这期间新进程已经在跑 → 「我改了怎么没生效」的元凶。
     加 `TimeoutStopSec=6` + `KillMode=mixed` + uvicorn `--timeout-graceful-shutdown 3`
     → **重启 0.15 秒**。
   - **启动页可能不退**：原来只靠两帧 `requestAnimationFrame`。页面若在加载那一刻
     处于后台，rAF 会被浏览器停掉 → 启动页一直挂着。加了 `setTimeout(..., 1500)`
     兜底，双保险。
   - **`ago()` 不认 ISO 字符串**：账号页显示「Invalid Date」。改成毫秒时间戳和
     ISO 串都收（`ts()`）。

### 这轮踩到的坑（比代码值钱）

1. **`projectRoot` 放哪儿，两种接口不一样** —— 这是最容易让按钮「点了没反应」的坑：
   - `projects/rag/*`、`projects/*` 等：**放查询串**（`requireProjectRefQuery(event)`）。
     塞进 body 会得到 `Invalid input: expected string, received undefined`。
   - `workspace-files/*`：**放请求体**（`resolveWorkspaceFileTarget(..., body)`）。
   写新界面之前先看一眼那个路由文件用的是哪个 helper。
2. **有的接口根本没有 GET**：`projects/rag/memories`、`rag/events` 只有
   POST/PATCH/DELETE。要读记忆得走 `rag/overview` / `rag/subject` /
   `rag/search`（POST）。写死一个 GET 会拿到 Nuxt 返回的 HTML 首页（200），
   很容易误以为「通了」。**看到返回 HTML 就当这条路由不存在。**
3. **`agent/traces/recent` 的返回键是 `entries`**，不是 `items`/`traces`。
4. **会话没有「消息列表」接口**：正文走 `/sessions/{id}/events`，那是**SSE 流**，
   读不完（会一直挂着），静态页不能用。`/sessions/{id}` 给的是恢复快照。
   所以会话页只报状态 + 引导回对话页。
5. **`agent/profiles/source` 要 `fileName`，不是 `profileKey`**，传错 400。
6. **搜索是「按主体」的**：`rag/search` 必须给 `subjectPath`，没有全书一次搜。
   主体是平台模拟系统在磁盘上建的（`simulation/subjects/<id>`），接口建不出来 ——
   一个主体都没有时要说人话，别让用户对着空框发呆。
7. **SSE / 流式接口验收要小心**：`http.client` 会一直等 chunk 直到超时，
   看起来像「接口挂了」，其实是设计如此。

### 验收方法（这轮确立的）

1. **静态对账**：扫前端调用的接口 vs 后端真实存在的路由，抓「幽灵接口」。
2. **真机全接口冒烟**（`tools/smoke_api.py`）：只读的照打、写操作的自建自删，
   跑完不留痕。第一次跑就抓出听书 500。
3. **探结构再写界面**（`tools/probe_shapes.py`）：把每个要用的 GET 打一遍、
   打印真实返回结构。**不探结构就写界面 = 一定会做出空壳。**
4. **界面验收要点进最里层**：不只是「页面有内容」，而是要真点进目录、真打开文件、
   真读到正文。12 件工具逐件点 + 深处再点一层 + 抓 `window.onerror`。

### 无头浏览器的两个假象（别再被骗）

1. **页面是 `hidden` 时 `requestAnimationFrame` 一次都不触发**，CSS 过渡也不跑。
   于是「启动页不退」「动画没动」都可能是**假象**。先把页面变可见：
   `cdp('Emulation.setFocusEmulationEnabled', enabled=True)`，再截再验。
2. **harness 的截图 helper 返回共享路径，会拿到旧图**；一律用
   `cdp('Page.captureScreenshot', format='png')` 自己写文件。

## 第五轮（2026-09-19 · 修「点下载更新没反应」）

### 症状
用户原话：「有新版本更新，我是不能直接在这上面点下载的，它是无用的」。

### 真因
`关于` 页那个「下载 / 更新」是个**普通网页链接** `<a href="apk" download>`。
在 App 里点下去，WebView 会把它交给 `onDownloadStart`，而当时的实现是
`openExternally(url)` —— **用一个 `Intent.ACTION_VIEW` 把安装包地址丢给手机浏览器**。

这条路在真机上太容易断：
- 手机没有默认浏览器 / 浏览器被安全策略拦；
- 下载完用户根本找不着文件；
- 有些系统直接静默什么都不做。

表现出来就是「点了下载一点用都没有」。**真 App 应该自己下、自己弹安装。**

### 修法（三层，层层兜底）
1. **`onDownloadStart` 就地接管**（最关键的一层）：只要是安装包
   （`isApkDownload()` 同时认 MIME `application/vnd.android.package-archive`、
   响应头的 `.apk`、以及 URL 结尾 `/apk` 或 `.apk`），就走 `startApkDownload()`
   而不是丢给浏览器。**放在这一层意味着：网页那边哪怕还是老的 `<a href="apk">`
   写法，也能自动生效** —— 用户装上新包后不需要网页配合。
2. **`startApkDownload()` 全流程自理**：`DownloadManager` 排队下载
   （`setDestinationInExternalPublicDir(DIRECTORY_DOWNLOADS, ...)`），
   后台线程**轮询**状态（不注册广播 —— Android 13+ 动态注册要额外声明导出标志，
   轮询更省事也更稳），下载完 `getUriForDownloadedFile()` 拿系统给的
   `content://` URI，直接 `Intent.ACTION_VIEW` + `package-archive` 拉系统安装界面
   （`FLAG_GRANT_READ_URI_PERMISSION` 必须加）。失败才退回浏览器。
   **不用 FileProvider** —— 工程是 aapt2 + javac + d8，没有 AndroidX，
   `androidx.core.content.FileProvider` 用不了；DownloadManager 给的 URI 是系统
   Downloads provider 出的，天然带读权限，正好绕开这个限制。
3. **JS 桥 `Android.downloadApk(url, name)`** + 服务端 `GET /api/apk/version`
   （读 `apk/apk-version.json`，由 `build.sh` 打包时自动生成，含
   versionCode/versionName/size/sha256）：网页拿它跟 `Android.getVersionCode()`
   比，比自己新就把「安卓安装包」那行改成 **「有新版本 v1.2 · 146KB ＋ 下载更新」**。
   已经最新就不打扰。

### 清单改动
`<uses-permission android:name="android.permission.REQUEST_INSTALL_PACKAGES" />`
（Android 8+ 要拉安装界面必须有）。

### 验证（四种情况都点过）
| 情况 | 期望 | 实测 |
|---|---|---|
| App 内 + 有新版 | 显示「有新版本 v1.2 · 146KB」+ 下载更新 | ✅ 点了原生收到 `["http://…/apk", "写作台-1.2.apk"]` |
| App 内 + 已最新 | 只显示「下载 / 更新」，不打扰 | ✅ |
| 纯网页 | 显示「网页版」+ 按钮走浏览器下载 | ✅ |
| 已最新无新版清单 | 不报错、按钮保留 | ✅ |

另外：公网 `/nbapp/apk` 下来的包与打包产物 **sha256 逐字节一致**。

### 教训
**别把「下载/安装」这种关键动作外包给系统的另一个 App。** 浏览器在不在、让不让下、
下载完放哪儿，全不由你控制；用户看到的就只有「点了没用」。
凡是「更新自己」这种事，App 必须自己下自己装。

### 操作纪律（血的教训）

**不许拿用户的真实数据当试验品。** 这轮我用脚本点「列表第一行」去测删除，
结果点中的是系统文件 `upload/index.md`，把用户的目录索引删了
（已从平台模板 `assets/workspace/.nbook/templates/project-directory-templates/`
逐字节恢复）。以后：
- 自测一律**先建一个名字唯一的靶子**，再用**名字**选中它，绝不点「第一行」；
- 破坏性操作（删除/覆盖）的自动化测试，靶子必须是自己刚建的。

## 第六轮（2026-09-19 · 听书不响 / 点击反馈糊一大片）

用户原话：「点击听书那个按钮，它的那个喇叭的UI会变到别的地方，整体bug很多，
会直接跳到小说里面，也没有声音」「我现在很多东西点的时候…你是直接框了一个大区域
在那儿震动…我想要的是我点一个球，那么就只有这个球的身体有波动」

### 一、听书：点了半天不出声

**真因分两层，两层都要治。**

1. **后端**：`/api/tts` 把**整章**塞给 edge-tts 一次性 `save()` 成一个 mp3。
   一章 4000 字 ≈ 13 分钟音频、4.7MB，生成要几十秒。按下去界面**毫无变化**，
   几十秒后才有声 —— 任何人都会判定「坏了」。
2. **前端**：按钮只切了个颜色类（`--accent #8c6a4a` vs `--ink-2 #6f6252`，
   两个颜色几乎一样），**图标和文字从来不跟着变** → 完全看不出开没开。

**改法**

- 后端把正文按句切成小段（≈240 字/段，`_tts_segments`），新增
  `GET /api/tts/segments`（只给段数，便宜）和 `GET /api/tts/seg?…&i=N`
  （第 N 段 mp3，按段缓存）。**第一段 1.7 秒出水**（整章要几十秒）。
- 前端一段一段播，播完自动接下一段，并**预取下一段**（播完才去要会有空档）。
- 按钮全程有状态：听书 → 准备中（转圈）→ 停止（暂停图标 + 底色块 + 呼吸小点）。
- 一章读完自动接下一章。
- 新增设置项「**页面跟着朗读走**」（`ttsFollow`，默认开）：按段进度换算页码跟着翻；
  只跟「开读时那一章」，用户翻到别章就不管。

**验证**：段 0→20→40 时页面 0→5→9（共 17 页）；第 0 段播完自动接第 1 段；
停止后按钮复位、零残留。

### 二、点击反馈糊了一大片（两套波纹在打架）

**真因**：`app.js` 里**同时存在两套水波纹实现**。

- 旧那套半径 `max(w,h) * 2.1` —— 54px 的小按钮也铺出 **113px** 的一大团，
  而且 `has-ripple` 类加完从不摘掉。
- 新那套（按指尖定位、半径封顶）也在跑 → 一次点击冒**两个圈**。

另外一堆 `:active` 挂在**容器**上：`.settings-row:active{background}`、
`.row:active{background}`、`.book-card:active{transform:scale(.988)}` ——
点行里一个小按钮，**整行**都变色/缩放。这就是「框了一个大区域在那儿震动」。

**改法（规矩定死：波纹只出现在你手指点住的那个元素里）**

- 删掉旧那套，只留一套。
- 半径 `clamp(hypot(w,h) * 0.42, 26, 64)`：小按钮正好整颗亮，大卡片只在指尖起一圈。
- 元素不是 `relative` 就临时加上、`overflow` 是 `visible` 就临时 `hidden`，
  动画结束**还原行内样式**（不改类、不留后患）。
- 删掉所有**容器级** `:active` 变色/缩放（`.settings-row`/`.row`/`.rd-toc-item`/
  `.lore-item`/`.t-row`/`.book-card:active` 的 scale）。

**验证**：54×36 小按钮 → 波纹 54.58px（只有按钮自己）；366×108 大卡片 → 封顶 128px；
结束 0 残留、行内样式已还原。

### 三、顺手修掉的别的 bug

- **安卓返回键**：工具详情页（含文件浏览器多级目录）按返回，以前**一步跳回书架**，
  丢掉中间层级。现在接 `Tools.back()` 一层一层退：
  工具详情 → 工具宫格 → 书架 → 再按才问「再按一次退出」。
- **换音色/语速**：以前弹「已停止听书」再自己重新开始，很跳。改成静默重启。
