# 克制白描

## 用词
- 动词优先，形容词克制：一件事只给一个最准的动词，不叠两个近义形容词。
- 不写"仿佛""似乎""如同"这类比喻连接词，除非比喻本身推进信息。
- 感官细节限定在视角人物当下真能感知到的范围（嗅觉、触觉、温度优先），不写他看不见的东西。

## 句式
- 长短交替：连续三个长句之后必须出现一个短句。
- 对话独立成段，动作跟在对话后面，不夹在中间。
- 不用排比，不用三个并列结构收尾。

## 禁用
- 禁用"这一切""命运""某种""说不清"这类含糊的总括词。
- 禁用句末总结：不在一段结尾替读者总结这一段讲了什么。
- 禁用情绪标签（"他很愤怒"），只写能看出愤怒的动作与生理反应。
