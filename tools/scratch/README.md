# tools/scratch · 一次性分析脚本（不是测试，不参与交付）

这些是**排查用的临时脚本**，跟产品、跟测试套件都没关系，放在 `tools/` 根下会把
"哪些是判据、哪些是随手写的"搅在一起（第 12 轮清理）。

* `ans.py` / `msgchk.py` / `msgchk2.py` —— 从 Codex 会话日志里捞"监督人说过什么"，
  里面写死了一份 rollout 文件名，早就过期了。
* `cmds.py` / `sess.py` —— 同一批：统计某次会话里执行过哪些命令。

留着只为"万一还想回看当时的原始记录"；**谁也别 import 它们**。
真正要看"这一轮做了什么、怎么验的"，看 `docs/进度.md` 和 `docs/*.json`。
