# 变更记录
#
# 2.8.0
#   单人或全套执行预设支持按步骤分别配置。此前该预设仅三个字段，而覆盖七个步骤，
#   各步骤无法独立调整。现按执行主体划分为五组：
#     ① 主创（排计划 / 出主张 / 回应与收敛 / 定稿 / 汇总）
#     ② 取上下文  ③ 查证  ④ 正文写作（写初稿 / 按批注改稿）  ⑤ 挑刺
#   执行至对应步骤时，将该组配置并入该步骤的任务要求。
#
# 2.7.9
#   模型名称完整显示：界面此前移除方括号形式的渠道标识并截断名称，
#   导致同一模型的不同渠道版本无法区分。现按原名完整显示。
#   模型列表统一命名取值逻辑（接口字段为 id / name / source）。
#   预设页全套执行预设调整至首位，此前因排序缺失被置于末位。
#
# 2.7.8
#   新增全套执行预设：将主创、取上下文、查证、正文写作、挑刺、润色合并为单一配置，
#   供非分工模式使用。提示词包含自检约束：完成写作后须自行列出不少于三条具体问题，
#   并据此完成修订后输出完整正文。
#
# 2.7.7
#   预设新增六个执行主体的尺度配置项，均可在界面查看与修改，默认值已填充。
#   非分工模式改为执行完整步骤序列并显示步骤进度（讨论 4 步 / 计划 4 步 / 执行 7 步）。
#   新增全文检索：按关键词检索全书正文并跳转至对应章节。
#   新增自定义文风条目，保存后进入可选列表，可选用与删除。
#   新增会话新建入口；新增自动写作开关，含四项停止条件。
#   调整联网与自动写作开关在输入区的垂直位置。
#
# 2.7.6
#   移除安装包内嵌的 Python 运行时。该运行时在早期版本中用于本机后端，
#   方案废弃后仍保留在包内（未压缩约 31MB），既不参与运行，
#   又存在被误启用后连接空后端的风险。移除后安装包体积由约 27.5MB 降至约 0.5MB。
#
# 2.7.5
#   修复界面卡顿。此前的实现将 JSON 请求经由同步桥接方法发出，
#   每次请求均阻塞界面线程等待网络返回。现改由异步请求发出，
#   桥接方法仅保留给必须同步取值的操作。
#
# 2.7.4
#   修复重复登录问题。安装包内页面以本地文件方式加载，该来源下浏览器不保留
#   Cookie 与本地存储，凭据无法持久化。现于登录成功后持久化保存凭据，
#   启动时静默恢复登录状态。更新检查超时由 60 秒调整为 10 秒。
#
# 2.7.3
#   新增自检面板与前端版本标识（该面板已于 2.7.4 移除）。
#
# 2.7.2
#   新增网页端更新功能：可检查远端更新并一键更新后端与前端。
#   更新采用仅快进方式，本地存在未提交改动时中止；支持通过本地代理访问远端。
#
# 2.7.1
#   修复重复登录与重复请求。登录凭据改为持久化存储；
#   同一时刻的重复 GET 请求进行合并，并加入短时缓存，写操作后立即失效。
#   口令复制改用 execCommand 兼容非 HTTPS 环境；修复设置页说明文字溢出裁切。
#
# 2.7.0
#   开源发布：新增 AGPL-3.0 许可证、README 与依赖清单。
#   新增模型参数配置面板（上下文长度、单次输出上限、推理开关、高级参数）。
#   工作方式调整为讨论 / 计划 / 执行三种，各支持分工与单人两种模式。
#   新增联网搜索开关；新增通用空白安装包（不含书稿与服务器地址）。
#   修复依赖清单缺失 python-multipart 导致服务无法启动的问题。
